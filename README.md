# Task Management System

A simple Task Management System built with Laravel and MySQL to manage daily tasks.

## Features
- Create new tasks
- View all tasks
- Edit and update tasks
- Delete tasks
- Set task due dates
- Manage task status: Pending, In Progress, Completed
- Form validation
- Success messages

## Technologies Used
- PHP
- Laravel
- MySQL
- Blade Templates
- HTML
- CSS
- Git and GitHub

## Installation

1. Clone this repository.
2. Run `composer install`.
3. Copy `.env.example` to `.env`.
4. Create a MySQL database named `task_management`.
5. Update the database credentials in `.env`.
6. Run `php artisan key:generate`.
7. Run `php artisan migrate`.
8. Start the development server with `php artisan serve`.
